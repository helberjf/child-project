# Aula 09 - Arrays

## Ideia principal

Arrays sao listas. Uma lista pode guardar varios monstros.

## No jogo

`monsters` e um array. Cada fase coloca uma quantidade diferente dentro dele.

## Desafio

Veja como a fase 3 cria 3 monstros.

## Exercicio

Mude `monsterCount` da fase 2 para 3 e teste.
