# Aula 02 - CSS

## Ideia principal

CSS e a roupa do jogo. Ele escolhe cores, tamanhos, sombras e movimentos suaves.

## No jogo

O arquivo `css/style.css` deixa os botoes coloridos, cria os fundos das fases e anima as particulas.

## Desafio

Procure `.background-forest` e mude uma cor da floresta.

## Exercicio

Crie uma cor nova para o botao principal.

## Curiosidade

`border-radius: 8px` arredonda os cantos, como uma peca de montar sem pontas.
