# Aula 07 - If

## Ideia principal

`if` e uma pergunta para o computador. Se a resposta for sim, ele faz uma acao.

## No jogo

Se as vidas chegam a zero, o jogo mostra Game Over.

## Desafio

Encontre `if (player.lives <= 0)`.

## Exercicio

Crie uma condicao para mostrar uma mensagem quando a pontuacao passar de 50.

## Curiosidade

`if` significa "se" em ingles.
