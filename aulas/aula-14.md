# Aula 14 - Projeto Final

## Ideia principal

Um projeto completo nasce juntando pequenas partes simples.

## No jogo

HTML cria a estrutura, CSS deixa bonito e JavaScript faz tudo reagir.

## Desafio

Jogue ate o chefao e observe quais regras mudam em cada fase.

## Exercicio

Crie a fase 8 com um novo fundo, monstros diferentes e outra dica educativa.

## Curiosidade

Programadores melhoram projetos em passos pequenos, testando e salvando cada melhoria.
