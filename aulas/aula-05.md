# Aula 05 - Funcoes

## Ideia principal

Funcoes sao comandos com nome. Elas ajudam o codigo a ficar organizado.

## No jogo

`renderHud` atualiza o placar, `playSound` toca sons e `createExplosion` cria particulas.

## Desafio

Ache uma funcao que comeca com a palavra `render`.

## Exercicio

Crie uma mensagem diferente dentro de `finishGame`.

## Curiosidade

Funcoes evitam repetir o mesmo codigo muitas vezes.
